# Try the viewer without models

This sample lets you explore the interface with Docker. It needs no GPU, model
weights or private basketball footage.

From the repository root:

```bash
docker compose up --build -d viewer
```

Open <http://127.0.0.1:8766>. Select **EN** for English. Explore video overlays,
player statistics, individual shot review and team maps. Use **Compare** to view
both teams side by side.

Stop the sample with:

```bash
docker compose down
```

If you already have local Python, `make demo-native PYTHON=python3` serves the same sample on
the same port without Docker.

## What the sample contains

`videos/synthetic.mp4` and `runs/synthetic/` are generated by
[mlops/demo.py](../../mlops/demo.py). The video and observations are scripted:
six player identities, positions, poses, ball contacts, a calibration gap and two
camera segments. Team control alternates; the second segment reverses court
direction. A ball-visibility gap demonstrates unavailable phase classification.

The viewer uses these scripted observations to demonstrate playback, observed
distance, heatmaps and missing-data states. The visible team-control label comes
from the scenario, not a learned model or an input to the phase estimator.

**This is an interface sample, not an accuracy benchmark.** No model is trained
or run to generate it, and it contains no NBA footage or third-party checkpoints.
To analyze your own footage, use the [pipeline guide](../../pipeline/README.md).
